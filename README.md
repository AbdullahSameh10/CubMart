# 🛍️ CubMart Store

A modern, responsive front-end e-commerce website built with **HTML5**, **CSS3**, **Bootstrap 5**, and **Vanilla JavaScript**. Cub Store delivers a realistic online shopping experience by allowing users to browse products, manage a shopping cart, apply promotional discounts, review their order, and print a professional purchase receipt.

---

## 📖 Overview

Cub Store is a client-side e-commerce application developed to demonstrate modern front-end web development principles. The project focuses on creating a clean, responsive, and user-friendly shopping experience while showcasing JavaScript programming, dynamic DOM manipulation, and Bootstrap components.

The application runs entirely in the browser and does not require a backend server or database.

---

## ✨ Features

### 🛍️ Product Catalog
- Products organized into multiple categories
- Responsive product cards
- Product images and descriptions
- Original and discounted prices
- Add to Cart functionality
- Stock availability validation

### 🛒 Shopping Cart
- Floating shopping cart button
- Slide-in cart panel
- Dynamic cart updates
- Increase and decrease product quantities
- Remove products from the cart
- Live cart item counter
- Empty cart handling

### 💰 Pricing & Discounts
- Automatic product discount calculation
- Promotional code support
- Combined discount percentage calculation
- Tax calculation
- Dynamic order summary
- Real-time total updates

### 🧾 Checkout Experience
- Order review using a Bootstrap modal
- Professional receipt preview
- Receipt printing
- Order confirmation
- Automatic cart reset after successful checkout

### 📱 Responsive Design
- Mobile-first layout
- Optimized for desktops, tablets, and smartphones
- Built using the Bootstrap 5 Grid System
- Smooth animations and modern UI components
